# Smart-Hospital-Management-System

A C# desktop application designed to make everyday hospital operations easier to manage.

Built using C# Windows Forms and Microsoft SQL Server, this academic project brings patient records, doctor information, appointments, and billing into one system.

The goal is simple: reduce scattered record-keeping and make hospital information easier for staff to access and manage.

## Who Is This System For?

Designed primarily for hospital administrators, receptionists, and doctors.

**Administrators**: Manage and oversee hospital information.

**Receptionists**: Handle patient registration and appointments.

**Doctors**: Access relevant patient and appointment information.

The system is intended for small hospitals and clinics looking to organize routine administrative tasks.

## Key Features

**Role-Based Login**: Supports different user roles, including Admin, Doctor, and Receptionist.

**Patient Management**: Register patients and maintain their information.

**Doctor Management**: Organize doctor profiles and relevant details.

**Appointment Scheduling**: Manage appointments and track their status.

**Billing Management**: Keep hospital billing information organized.

**Database Integration**: Store and retrieve records using Microsoft SQL Server.

## How the System Works

The application follows a straightforward hospital workflow:

**1. Login**

* Open the application.

* Select the appropriate user role.

* Enter the required login details.

**2. Manage Hospital Records**

* Register new patients.

* View or update existing patient information.

* Maintain doctor details.

**3. Schedule Appointments**

* Select a patient and doctor.

* Enter the appointment details.

* Track or update appointment information.

**4. Manage Reports**

* Tracking overall reports of the hospital

* Track total doctors assigned with total patients to get the revenue statistics

**5. Handle Billing**

* Access the billing section.

* Record and manage billing details.

**6. Maintain Information**

* Hospital records are managed through the application's SQL Server database.

* Staff can access relevant information through the available application forms.
